# Isometric 3D City Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Capture window's City tab into a live 3D isometric Kenney city that the on-screen pointer steers, that persists across days, and that grows road tiers, roof colours by hour, day and night, neighbour-shaped buildings and distance unlocks.

**Architecture:** Rust capture records the pointer in global screen points to `cursor-YYYY-MM-DD.jsonl`. The pure TypeScript `CitySim` (vitest-tested) gets diamond-grid steering, a distance counter and a snapshot; the window restores the snapshot and replays newer records. A Three.js view draws the sim with one `InstancedMesh` per Kenney model, only near the roller and only when something changed. Pure helpers (road pieces, roof bands, sky, kinds, unlocks) are tested in node; the WebGL view is checked by screenshots.

**Tech Stack:** Tauri v2 + Rust (capture), Vite 8 + TypeScript 5.9, Three.js 0.186.1 (already installed), PixiJS 8 (Heat tab only), vitest 5.

**Spec:** `docs/specs/2026-11-03-iso-city-design.md`

## Global Constraints

- Three.js stays at `0.186.1`, `@types/three` at `0.186.0`.
- Window stays 512×348, always on top; 3D renderer pixel ratio 2; at most 30 frames a second; no frames while nothing changes; no real-time shadows; Lambert materials.
- Roller parks 30 s after the last pointer movement, slowing over the whole 30 s (`idleStopMs: 30_000`, `slowMs: 30_000`, already built).
- Roller still flattens houses in its way.
- No streaks, notifications, toasts, guilt copy, random drops or expiring goals anywhere.
- Window tabs: City (3D) and Heat. Farm and Monster code stays in the repo but leaves the window and the dev page.
- A change to sim rules bumps `CITY_RULES_VERSION`; a snapshot with another version is ignored and the city regrows from every record.
- Kenney assets are CC0 and committed under `prototypes/form-study/src/assets/kenney/<kit>/` with each kit's own `Textures/colormap.png`.
- Commit after each task; never push.

## Review Focus

1. Pointer on an external display (negative or > laptop-width coordinates) still steers and counts distance. → Task 1 test `points_pass_through_unclamped`; Task 3 test "steers from points far outside 0–1".
2. A day file containing both old 0–1 trackpad records and new point records is never mixed in: only `cursor-*.jsonl` is read. → Task 1 test `days_text_reads_only_cursor_files`.
3. Window closed mid-drive, reopened next morning: city identical to a full replay, roller where it parked. → Task 4 test "snapshot plus later records equals full replay".
4. Snapshot written by an older rules version, or corrupt JSON: city regrows instead of crashing. → Task 4 tests "ignores a snapshot from another rules version" and "ignores broken snapshot text".
5. Roof band at the hour boundaries and across midnight in local time (05:59 → night, 06:00 → morning, 23:59 → evening). → Task 6 test "roofBand uses local hour edges".

### Task 3: Diamond steering and pointer distance in CitySim

**Files:**
- Create: `prototypes/form-study/src/sims/steer.ts`
- Modify: `prototypes/form-study/src/sims/city.ts`
- Test: `test/steer.test.ts` (new), `test/city.test.ts`

**Interfaces:**
- Produces `headingFor(dx: number, dy: number, current: Dir): Dir` (screen points, y down). Screen angles (y up) of the grid headings in the 2:1 diamond view: N `+26.57°` (↗), E `-26.57°` (↘), S `-153.43°` (↙), W `+153.43°` (↖).
- Produces `CitySim.distance: number` — summed pointer path length in points across all strokes.

Rule: angle `θ = atan2(-dy, dx)`; distances to the four heading angles; `best` = smallest; candidates = headings within `best + 15°`; if `current` is a candidate keep it; else drop the reverse of `current` and take the nearest remaining.

- [ ] **Step 1: Failing tests** in `steer.test.ts`: "push right keeps ↗" (`headingFor(10, 0, 3) === 3`); "push right from ↙ turns ↘" (`headingFor(10, 0, 1) === 0`: N and E tie, N is the U-turn from S); "push down from ↗ turns ↘" (`headingFor(0, 10, 3) === 0`); "a clear diagonal wins" (`headingFor(-20, -10, 0) === 2`, up-left = W). In `city.test.ts`: change `cfg.steerMin` to 40 and the swipe helper to move `dx, dy` in points (scale existing 0.1 moves to 100); update expected roads to the new headings; add "steers from points far outside 0–1" (anchor at `(3000, -500)`, move to `(3100, -450)` → heading E=0); add "sums pointer distance in points" (a stroke `(0,0)→(30,40)→(30,100)` gives `distance === 110`).
- [ ] **Step 2: Run** tests — expected: new ones fail.
- [ ] **Step 3: Implement** `headingFor`; in `CitySim.addPoints` steer when `Math.hypot(dx, dy) >= steerMin` using `headingFor`; keep a last point per finger for `distance`.
